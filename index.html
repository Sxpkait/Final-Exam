ติวสอบปลายภาค HTML · CSS · JS

สรุปสั้น ตัวอย่างจากโปรเจกต์ "คู่มือสัตว์เลี้ยง" และแบบฝึกหัดตามโครงข้อสอบ 5 ตอน

1. โครงหน้าเว็บ

<!DOCTYPE html>
<html lang="th">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link rel="stylesheet" href="css/style.css">
  <title>คู่มือสัตว์เลี้ยง</title>
</head>
<body>
  <header>...</header>
  <nav>...</nav>
  <main>...</main>
  <footer>...</footer>
</body>
</html>

<head> เก็บข้อมูลหน้าเว็บ (ไม่แสดงเป็นเนื้อหา) ส่วน <body> คือสิ่งที่ผู้ใช้เห็น แท็ก <link> ต้องอยู่ใน head

เคล็ดลับ meta viewport: บรรทัด meta name="viewport" ทำให้เว็บแสดงผลพอดีหน้าจอมือถือ ถ้าไม่ใส่ มือถือจะย่อทั้งหน้าจนเล็กมาก

2. Tag, Attribute, Value

<a href="cat.html" class="active">แมว</a>
ส่วนคืออะไร
atag (แท็ก) = ลิงก์
href, classattribute (คุณสมบัติของแท็ก)
"cat.html", "active"value (ค่าของ attribute)
แมวเนื้อหาระหว่างแท็กเปิด-ปิด

3. แท็กที่ต้องจำ

แท็กหน้าที่ตัวอย่างจากโปรเจกต์
h1–h6หัวข้อ<h2>ปลาทอง</h2>

4. Form และ Table (ที่เรียนใน style-pets02)

<input type="radio" name="pet" id="r1">

<table>

for ของ label ต้องตรงกับ id ของ input ส่วน radio ที่อยู่กลุ่มเดียวกันใช้ name เดียวกัน ตารางใช้ tr = แถว, th = หัวคอลัมน์, td = ช่องข้อมูล

2. ตัวแปร CSS

:root {
  --primary-color: #111111;
}
.header-title {
  color: var(--primary-color);
}

ประกาศด้วย --ชื่อ ใน :root แล้วเรียกใช้ด้วย var(--ชื่อ) แก้ที่เดียว เปลี่ยนทั้งเว็บ

3. Box model

จากใน element ออกมา: content → padding (ระยะในกรอบ) → border (เส้นขอบ) → margin (ระยะนอกกรอบ)

* { box-sizing: border-box; margin: 0; padding: 0; }

border-box ทำให้ width ที่ตั้งไว้นับรวม padding และ border แล้ว คำนวณขนาดง่ายขึ้น

4. Flexbox และ Grid

nav {
  display: flex;            /* เรียงแนวนอน */
  justify-content: center;  /* จัดกลางตามแกนหลัก */
  flex-wrap: wrap;          /* ล้นแล้วขึ้นบรรทัดใหม่ */
  gap: .75rem;
}
.pet-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 1.5rem;
}

Flex เหมาะกับแถวเดียว (เมนู ปุ่ม) ส่วน Grid เหมาะกับหลายแถวหลายคอลัมน์ (การ์ดสัตว์)

5. ทำให้รองรับมือถือ (Responsive)

@media (max-width: 480px) {
  .info-grid {
    grid-template-columns: 1fr;  /* มือถือเหลือ 1 คอลัมน์ */
  }
}

สูตรรองรับมือถือมี 3 อย่าง: ใส่ meta viewport, ใช้หน่วยยืดหยุ่น (%, rem, fr) และใช้ @media ปรับเลย์เอาต์ตามความกว้างจอ

6. Hover และ Transition

.pet-card img { transition: transform 0.25s; }
.pet-card:hover img { transform: translate(-4px) scale(1.03); }

2. Event: ตอบสนองการกด

  detail.classList.toggle("hidden");
});

classList.toggle("hidden") = ถ้ามี class นี้อยู่ให้ลบ ถ้าไม่มีให้เพิ่ม ใช้คู่กับ CSS .hidden { display: none; } ที่มีใน style-pets03.css

ลองกดดู

โกลเด้น รีทรีฟเวอร์: เป็นมิตร ฉลาด ภักดี และรักครอบครัว

3. ตัวกรองหมวดหมู่ (แนวเดียวกับ .category-btn)

const buttons = document.querySelectorAll(".category-btn");
const cards   = document.querySelectorAll(".pet-card");

buttons.forEach(function (b) {
  b.addEventListener("click", function () {
    buttons.forEach(x => x.classList.remove("active"));
    b.classList.add("active");
    cards.forEach(function (c) {
      const show = b.dataset.cat === "all" || c.dataset.cat === b.dataset.cat;
      c.classList.toggle("hidden", !show);
    });
  });
});

อ่านโค้ดทีละบรรทัดแล้วอธิบายเป็นคำพูดให้ได้ ข้อสอบมักถามว่าบรรทัดนี้ทำอะไร
